## 1. 模组定位

<!-- 一句话：Athland 是什么类型的模组，给玩家什么核心体验。
     后续所有取舍都从这句推导。写「XX 内容的集合」这类无方向表述等于没写。 -->

- 定位：**冒险拓展**。以冒险与探索为主线，向原版未覆盖的领域拓展内容。
- 核心体验：**新奇**——玩家能遇到、尝试、建造原版没有的东西。
  - 承载「新奇」的两个优先方向：**材料**、**装备**。
  <!-- TODO：材料方向优先做哪一类（矿物 / 金属 / 合金 / 木材 / 宝石 / 建材）？装备方向优先做哪一类（武器 / 防具 / 工具 / 饰品）？定 1～2 个作为第一个功能的落点。 -->
- 与原版的关系：**补完 + 扩展**。补上原版世界观与玩法链条的缺口，同时扩展原版已有内容的深度与广度。
  - **补完**＝原版缺了这一类内容，补上后原版玩法链条才完整。典型：**新材料**（如原版只有铁 / 金，缺铜、锡、银一类）、**新作物**（如原版只有小麦胡萝卜，缺其他作物）。
  - **扩展**＝原版已有这一类内容，但做得不够深 / 不够多，在此之上加深。典型：原版有武器但只有单一材质与单一升级线，可扩展为多材质 + 锻打 / 附魔路线。
